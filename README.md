# Raybot
- Projeto de chatbot desenvolvido em Django com HTML, CSS
- Tratamento de dados via Pandas e Spark
- Consultas parametrizadas ao banco de dados postgresql
- Uso da api OpenAI

## Como rodar
- Entre na pasta raybot
- Rode python manage.py makemigrations
- Rode python manage.py migrate
- Rode python manage.py runserver
- Entre na url fornecida
